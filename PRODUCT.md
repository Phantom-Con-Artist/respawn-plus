# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

A Tauri v2 desktop app for Linux: the interface is a web view (Vite, vanilla JavaScript, one stylesheet) in a frameless window with its own window controls. The marketing site in `website/` is a separate surface.

## Users

Mod-curious Linux players: people who want to play Windows games with mods, mod managers, script extenders and trainers the way they would on Windows, without learning Wine, Proton, prefixes or sandboxing. Their moment: open Vessel, pick a game, choose how to play it (vanilla, with a trainer, modded through a mod manager, or modded with a trainer), press Play, and get to the game.

Power modders who know Proton, prefixes and mod managers are a secondary audience; the room's detailed controls exist for them but are not the first thing a player meets.

## Product Purpose

Vessel runs Windows games on Linux together with the apps players use around them. Each game gets its own room; the player chooses what starts the game and which companion apps open with it, and Vessel starts them together. Success is a player getting from "I want to play this, this way" to the game on screen in one press, and back to a working setup if something breaks.

## Positioning

A game and its apps live in one room. Each game's room is its own sandbox (bubblewrap) with one Wine/Proton prefix and one container, so the game, a mod manager such as Mod Organizer 2, a script extender and a trainer run together and can see each other, with checkpoints to recover the room, without touching the rest of the user's system. Neighbouring launchers run a game; Vessel runs a game with its whole modding setup as one unit.

## Operating Context

- Rooms: per-game sandboxes with a private home, process and network namespace, one Wine/Proton prefix, and on Wayland desktops a separate window per app. Rooms close when their last app exits.
- Companion apps belong to one game and have a kind: mod manager, script extender, trainer or utility. Mod managers and script extenders can start the game ("Play through"); trainers and utilities attach to a running game.
- Runtimes: UMU with Proton (for example GE-Proton), system Wine, Lutris Wine, Flatpak/native Steam Proton, or a runner the user picks.
- Library data lives in a local SQLite database under `~/.local/share/vessel`; launch logs under `~/.local/state/vessel`.
- Room recovery: automatic and manual checkpoints; restore keeps current saves.
- Shared Windows dependency packages (for example Visual C++ or .NET runtimes) are imported once and mounted read-only into the rooms that need them.

## Capabilities and Constraints

- Agnostic by rule (see `AGENTS.md`): no game, tool, mod manager, trainer or platform is special-cased in code; behaviour follows the companion app's kind and the user's settings. Values come from settings or the host, never guessed constants.
- Works on any Linux distribution and desktop; secure rooms need a Wayland session for a display.
- Display modes (fullscreen, borderless, windowed) apply only in the one-window room display; with separate windows the game keeps its own settings.
- Not claimed: universal Windows compatibility, anti-cheat support, or that every mod manager or trainer feature works. Only what was run is stated.
- Undecided: one-click setup helpers for specific mod managers; release packaging (Lite/Full RPM and DEB) is groundwork, not shipped.

## Brand Commitments

- Name: Vessel (formerly Respawn+). License: MIT.
- Logo: two slanted panels, cyan `#18e6e4` and deep teal `#0b1c1f` (`public/brand/`, generated by `scripts/generate-brand.mjs`); the deep panel lightens on dark grounds.
- Stated by the user for the launcher's look: Swiss International Style minimalism; colour palettes named Milky, Night and Ashen plus the logo colours, used consistently; no rounded pill buttons; no glassmorphism or other "morphism". The user wants the experience "boring and easy".

## Evidence on Hand

- Verified on Fedora (KDE Plasma, Wayland) with GE-Proton 11-11 and UMU 1.4.4: Skyrim Special Edition 1.7.104 started from Mod Organizer 2.5.2 through SKSE 2.3.1 (SKSE and MO2's virtual file system loaded) with a standalone trainer attached in the same room, each as its own window.
- Mines (an MIT-licensed puzzle game, `test-games/`) is the developer test game.
- Artwork: `public/artwork/mines.png`; no other game art is owned. There are no users, testimonials, reviews, download counts or press; do not invent any.

## Product Principles

1. One press to play the way you want: the setup (what starts the game, what opens with it) is chosen once and Play does exactly that, described in plain words.
2. Say what will happen and what is happening: starting a room takes time, so the launcher always shows progress and never leaves a black or silent screen.
3. Agnostic by default: any game, any mod manager, any trainer, any Linux setup; no title gets special treatment.
4. Safe to experiment: the room is isolated and recoverable, so trying a mod or trainer never risks the rest of the system.
5. Advanced controls stay available but out of the player's way.
