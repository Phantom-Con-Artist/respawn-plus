# Library artwork

`mines.png` is a screenshot of the verified Windows Mines test game running under
UMU/GE-Proton. Mines is part of Simon Tatham's Portable Puzzle Collection and is
MIT licensed. Its original notice is in `test-games/licenses/mines-LICENCE.txt`
and is included with application packages displaying this screenshot.

Skyrim artwork is requested at runtime from the official Steam CDN for app 489830:
https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/489830/library_hero.jpg

Skyrim artwork belongs to Bethesda/ZeniMax and is not part of Vessel's MIT
license. It is not stored in this repository or bundled in the installers.
The source is the [official Steam store page](https://store.steampowered.com/app/489830/).
Image failures and games without recognized artwork display their game name.
